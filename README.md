# 1WINBET — Sportsbook + Casino Demo

Educational front-end prototype using virtual credits only.

Included:
- Responsive sportsbook UI
- Demo football odds and bet slip
- Virtual-credit demo settlement
- Casino lobby and 3-reel slot demo
- Demo account page

No real-money deposits, withdrawals, cash prizes, or real wagering are enabled.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save.
